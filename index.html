01 / The Problem

Delayed Pest & Disease Detection

⚠️

Severe Annual Crop Loss

Up to 35% yield lost to late pathogen identification across Indian smallholder farms.

📶

Rural Connectivity Gaps

Cloud-heavy agritech apps fail in low-signal farm zones, leaving farmers without help.

🔤

Language & Literacy Barriers

English-only text interfaces exclude hundreds of millions of regional-language farmers.

02 / Proposed Solution

🎙️

Voice-First Regional Guidance

Audio remedies delivered in Hindi, Marathi, Tamil, and Telugu via Bhashini APIs.

🌿

03 / User Workflow

Four-Step Field Diagnosis

1

Capture Leaf

Snap a photo using any budget Android camera. No special hardware needed.

2

Edge Inference

TFLite model classifies blight and disease in under 1.5 seconds on-device.

3

Voice Advisory

Plays step-by-step cure in local dialect — Hindi, Marathi, Tamil, or Telugu.

4

Outbreak Sync

Auto-syncs regional disease alerts to the cloud once internet is available.

04 / Architecture & Stack

Lightweight Edge-to-Cloud Stack

🔬

On-Device AI

Quantized MobileNetV3 model running via TensorFlow Lite — fits in <15 MB, works fully offline.

TensorFlow Lite MobileNetV3 PlantVillage Dataset
📱

Mobile & Voice

Flutter app with Bhashini ASR/TTS APIs delivering voice guidance in four regional Indian languages.

Flutter Bhashini API SQLite
⚙️

Backend & Sync

FastAPI backend with SQLite offline cache and PostgreSQL cloud database for outbreak sync.
